# GROTN Client Application

## ⚡️ Stack

- [`Next.js`](https://nextjs.org/)
- [`Typescript`](typescriptlang.org)
- [`Styled Components`](https://styled-components.com/)
- [`ESLint`](https://eslint.org/)
- [`Prettier`](https://prettier.io/)
- [`Husky`](https://github.com/typicode/husky)

## Running The App

- `yarn dev` Next dev
- `yarn start`: Next start
- `yarn build`: Next build
- `yarn analyze`: Generate bundle-analyzer
- `yarn lint`: Audit code quality

## 📂 Folder Structure

### `app`
Contains the main application pages and folders

### `components`
Reusable UI components used throughout the application.

### `hooks`
Custom React hooks to encapsulate reusable logic. 

### `layouts`
Layout components that define the structure of different pages.

### `lib`
Utility functions and libraries used in the application.

### `providers`
Context providers for managing global state and side effects such as toasters.

### `store`
State management setup, Zustand library.

### `styles`
Global and component-specific styles.

### `types`
TypeScript type definitions and interfaces.
