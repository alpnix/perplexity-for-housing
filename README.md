### Inspiration & Project Purpose

### Technical Approach & Perplexity's API
The first core phase of the project involves aggregating user profiles and housing datasets, preprocessing the data, and generating high-dimensional vector embeddings to store in a vector database for efficient similarity search and retrieval. MongoDB is used for both vector storage and database for other metadata.
